# cppDaily
gonna do some C++ learning from learncpp.com, practice problems and competitive programming. This is what I aim to do.

## Structure
Organized sequentially by concept. No copy-pasting or speedrunning tutorials—just actual typed code to build muscle memory.
- `Chapter_1/` - Fundamentals, compilation, iostream basics
- `Chapter_2/` - Functions, scoping, return values, and initialization forms

## Build Environment
- **Compiler:** g++ / MinGW
- **OS:** Windows 10  
- **Notes:** All files compiled cleanly with strict warning flags enabled to catch narrowing conversions and bad syntax early.
